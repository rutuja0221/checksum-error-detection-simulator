What Is Checksum Error Detection?

LEARN THE PROCESS

How Checksum Works

Checksum uses one's-complement addition to generate a value that helps the receiver detect errors in transmitted data.

1. Add Binary Words

Add the 8-bit data words using binary addition.

2. Handle Carry

Add any carry beyond 8 bits back to the lower 8 bits.

3. Invert the Bits

Change each 0 to 1 and each 1 to 0 to generate the checksum.

4. Verify at Receiver

Add the received words and checksum. An all-ones result means no error was detected.
